# CPP Module 01

CPP Module 01 is part of the C++ modules in the 42 curriculum and focuses on memory allocation, references, pointers to members, and the fundamentals of object lifetime. Through practical exercises, the project explores dynamic memory management, references, file streams, and the differences between stack and heap allocation. It strengthens understanding of C++ memory handling and object-oriented programming concepts.

**Technologies:** C++, Memory Management, Pointers, References, File I/O, Makefile, Git.
